# Security

Please report a security problem privately, by email to **hello@surfingdog.ai**, with "Security" in
the subject. Don't open a public issue or pull request for it.

Include what you found, how to reproduce it, and what someone could do with it. If you have a fix,
send it in the same email.

We reply as soon as we can, tell you what we will do about it, and let you know when it is fixed. We
credit you in the release notes if you would like that.

This covers this repository (the inbox, the self-host kit, the SDK and the spec) and the inboxes we
host at app.surfingdog.ai. Our published contact is also at
https://surfingdog.ai/.well-known/security.txt.

Supported versions: the latest release. Self-hosted inboxes update with `inbox update`.
